CentSible: personal expense tracker

Oct 2026 – present

A full-stack expense manager I’m building end to end, with an async FastAPI backend on PostgreSQL and a React and Material UI frontend.

  • Frontend covers protected routes, an auth context, expense CRUD with category filters, CSV export, a spending dashboard, and recurring expenses.
  • Cookie-based JWT auth with Google OAuth 2.0 sign-in and email password reset. Celery workers on RabbitMQ send the emails with exponential backoff retries.
  • A scheduled Celery beat job generates recurring expenses and is safe to run twice, using row-level locking to prevent duplicate charges.
  • Redis rate-limits the login endpoint. In progress: receipt upload to Cloudflare R2 and OpenRouter-based receipt scanning.

RouteWise: route stop optimizer

June 2026

Plans the cheapest fuel stops for a truck with a 500 mile range, over 8,100+ stations in PostgreSQL. Makes a single OpenRouteService call per request and resolves locations through a three-tier lookup (in-memory cache, own geocoded database, live geocoder as a last resort). Route downsampling and vectorized NumPy haversine checks cut a long multi-state query from about 44 s to 11 s (4x). Stops are picked greedily; a dynamic-programming variant was prototyped and documented, but not shipped.
